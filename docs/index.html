bigtransformer

a slightly bigger transformer, thrown together with hopes and dreams. reads a text file, trains on it, predicts the next words.

git clone https://github.com/adeveloperduck/bigtransformer

clones the repo and moves into it.

then create the venv

python3 -m venv .venv && source .venv/bin/activate

and after that, download the requirements

pip install -r requirements.txt

and you're good to go. run the project with

python3 mdl.py
